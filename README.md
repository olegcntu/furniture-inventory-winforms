# Furniture Inventory

Windows Forms desktop app for keeping an inventory of furniture items.

## Features

- Add and remove items
- List view backed by .NET collections
- Input validation

## Tech stack

C#, .NET Framework, Windows Forms

![Screenshot](https://user-images.githubusercontent.com/66881230/188309809-46c27714-0810-4b04-b52a-97de22e983a0.png)

## Getting started

Open `FurnitureAccounting.sln` in Visual Studio and run it.
